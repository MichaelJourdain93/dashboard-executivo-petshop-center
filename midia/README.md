## Notas técnicas

- O GIF é derivado do MP4 (`fps=10`, 1000 px de largura, paleta de 160 cores) e fica em ~4,4 MB — abaixo do limite de ~10 MB que o GitHub respeita para renderizar inline.
- O MP4 foi cortado em `crop=2280:1080:120:0` para remover as faixas pretas laterais da captura e teve o áudio removido (a trilha estava em silêncio, -91 dB).
- MP4 commitado **não toca inline** no markdown do GitHub — serve como arquivo em qualidade cheia para download. Quem toca inline é o GIF.
